# Notebooks

| File | Description |
|---|---|
| `ReneWind_Wind_Turbine_Failure_Prediction.ipynb` | End‑to‑end analysis: EDA → preprocessing → 7 neural‑network experiments → final model selection → business insights. |

## How to run

From the **repository root**:

```bash
jupyter notebook notebooks/ReneWind_Wind_Turbine_Failure_Prediction.ipynb
```

The notebook reads its data from `../data/Train.csv` and `../data/Test.csv`, so launching Jupyter from the repo root (or from inside `notebooks/`) both work.

> Don't want to install anything? A pre‑rendered HTML version is in
> [`../reports/ReneWind_Wind_Turbine_Failure_Prediction.html`](../reports/ReneWind_Wind_Turbine_Failure_Prediction.html).
